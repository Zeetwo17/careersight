🧬 Neural ODE Survival Model
Models the placement hazard as a continuous dynamical system, not a static snapshot. When a student completes a certification mid-month, the survival curve updates immediately — no wait for the monthly batch.
dh/dt = f_θ(h, t, x(t)) · 15ms CPU inference
🏦 Federated SHAP + DP (ε=1.0)
Multiple lenders improve from shared insights without exchanging raw student data. SHAP values leave each environment with calibrated Gaussian noise. A mathematical guarantee, not a policy promise.
FedSHAP (2022) · Google DP library · ε budget capped 10/yr
🛡️ Conformal Risk Control (ICML 2023)
Lender specifies: "≤ 10% false-negative rate on HIGH-risk students." CRC computes the minimum threshold satisfying this on any future distribution — without distributional assumptions. A theorem, not a heuristic.
E[r(ŷ,y)] ≤ α · updated weekly as outcomes arrive
🎯 Thompson Sampling Bandit Co-Pilot
Replaces static CATE ranking with Beta(α,β) posteriors per action per student segment. Regret bound O(√nK log K) — sublinear, meaning the system improves faster than it makes errors.
Actions: cert · resume · mock-interview · role-change · city-change
