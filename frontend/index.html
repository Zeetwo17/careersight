      Model Diagnostics
      CALIBRATION · BETA SCALING (KULL 2017)
      Reliability of P(placed_6m) after Beta calibration
      Each dot is a probability bin. Closer to the diagonal = better calibrated. Target ECE < 0.05 (Guo et al., 2017). Beta calibration corrects the systematic miscalibration of LightGBM under class imbalance (Caplin et al., 2022).
      FEDERATED SHAP · 2 LENDER SHARDS · GAUSSIAN DP
      Privacy-preserving driver attribution across lenders
      CENTRALIZED · NO DP
        FEDERATED · ε=1.0 · δ=1e-5
          Each lender computes local SHAP, L2-clips to C=1.0, adds Gaussian noise calibrated by σ = C·√(2·ln(1.25/δ))/ε (Dwork & Roth, 2014), then a coordinator aggregates the mean. Faithfulness gate: Spearman ρ ≥ 0.9 between centralized and DP-aggregated rankings (Saifullah et al., 2024, DOI 10.3389/frai.2024.1236947). Production path: flwr + opacus.PrivacyEngine.
          CAUSAL DISCOVERY · PC ALGORITHM (SPIRTES & GLYMOUR)
          Auto-discovered CPDAG and Markov blanket of P(placed_6m)
          causallearn.search.ConstraintBased.PC with Fisher-Z conditional independence test (α=0.05). Markov blanket = parents ∪ children ∪ spouses-of-children. Citations: Causal Learner Toolbox, Huber 2024.
          FAIRLEARN AUDIT · DPDP ACT 2023 §10
          Disparate-impact + equalised-odds across protected groups
          Thresholds (cited in tooltips): DI ≥ 0.80 (EEOC four-fifths rule, 29 CFR §1607.4D); DP diff < 0.10; EO diff < 0.10 (Hardt et al., 2016); EOpp diff < 0.05. Anchored in DPDP Act 2023 §10 + RBI Digital Lending Directions 2025. Mitigation path on breach: fairlearn.reductions.ExponentiatedGradient(DemographicParity(eps=0.05)) (Agarwal et al., 2018, arXiv:1803.02453).
          EDGE MODEL · BORN-AGAIN TREE (VIDAL & SCHIFFER 2020)
          Distilled single-tree for offline / WhatsApp-bot deployment
          The teacher LightGBM ensemble is distilled into a single decision tree with confidence-weighted soft-label training; thresholds are int16-quantised and serialised to JSON. Download via GET /api/edge_model and run the 30-line pure-Python evaluator shipped in backend/app/edge_model.py. The full payload fits in a single WhatsApp Business webhook response.
          COUNTERFACTUAL · DOUBLY-ROBUST ATE PER CO-PILOT ACTION
          EconML LinearDRLearner — uplift with 95% CI & placebo refuter
          Each Co-Pilot action's effect is estimated on confounded synthetic data where treatment assignment depends on relevant features. The naive treated-vs-control difference is shown alongside the doubly-robust ATE (Coston et al., 2020, arXiv:1909.00066), which corrects for confounding via cross-fit propensity + outcome models. Placebo refuter (random reassignment of treatment) should collapse the ATE to ~0; deviation > 1pp would invalidate the estimate.
          CO-PILOT BANDIT · BETA-BERNOULLI THOMPSON SAMPLING
          Action posteriors per (course-family × tier × risk-tier) segment
          α and β update via POST /api/record_outcome {segment_id, action_id, success}. Mean = α/(α+β); 95% credible interval from scipy.stats.beta.ppf. Regret bound O(√(nK log K)) — Russo & Van Roy, 2018 (arXiv:1707.02038).
          CONCEPT DRIFT · PSI (SIDDIQI 2006)
          Top features by Population Stability Index
          PSI thresholds: < 0.10 stable, 0.10–0.25 moderate (monitor), > 0.25 drift (retrain). KS p-values Bonferroni-corrected for the 57-feature search. Reference: training cohort. Current: synthetic BFSI-shock + cohort change.
